# Each Hero's display line is handwritten

This amends ADR 0005, which made San Francisco the only type family. Each Hero's display line is now set in Hand (Caveat, bold): the name, the roles, the note beside the Activity ring, the Playground title, the stacks, UIT and "Let's talk.", and the name in the Frame. Everything else stays San Francisco (Inter off Apple devices): Eyebrows, body text, numbers, Detail modules and the Frame's controls.

We chose this because the site's owner asked for a stylized, handwritten feel. One hand on one line per Hero gives the site a person's handwriting without giving up the iOS reading sizes; set throughout, a handwritten face would make the Details hard to read. Caveat won a side-by-side test against seven other faces because it is narrow enough to fit the name across a phone and still reads at note size. Flowing scripts such as Dancing Script and Sacramento lost at small sizes and on pale Skies.

The name's Motif follows the face: it is written out letter by letter, each letter wiped in from left to right like a pen stroke, instead of typed with a caret. The 48% stays San Francisco, because the Activity ring is iOS's own.
