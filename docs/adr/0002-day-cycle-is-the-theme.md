# The day cycle is the theme; there is no light/dark toggle

Each Time slot has one fixed Sky, Ink and Accent, so Dawn, Dusk and Twilight are dark while Sunrise and Midday are light. A light/dark toggle would need a second palette for every Time slot and would break the idea that scrolling moves through one day, so the site has none and does not follow the visitor's `prefers-color-scheme`.
